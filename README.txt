Jain Signature Studio - improved landing page (preview build)

Upload this whole folder to Netlify Drop (app.netlify.com/drop) to get the preview link.

Images: the page loads project photos, brand logos and the logo from the assets/ folder.
If a file is missing there, it automatically falls back to the original image on the client's server,
so the page still shows images. Best: copy the images from your saved page's "_files" folder into
  assets/projects/  (project-1.jpg ... project-12.jpg)
  assets/brands/    (the brand .png files)
  assets/logo.svg
